# Amazon Seller Data Chat

Talk to your Amazon seller data using natural language prompts. Ask questions, get insights, and explore your sales, inventory, and performance data through a simple chat interface.

## Features

- **Natural language queries** – Ask questions in plain English (e.g. "What were my top products last month?")
- **Amazon seller data** – Connect your Amazon Seller Central data (sales, inventory, reports)
- **Prompt-based interface** – No SQL or dashboards required; just type what you want to know
